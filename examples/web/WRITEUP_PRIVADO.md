# Write-up privado — web pendiente

Falta implementar una aplicación vulnerable de laboratorio, su adaptador por instancia y la resolución que recupere la flag inyectada. Requiere endpoint, aislamiento, disponibilidad y limpieza idempotente. No se levantó ningún servicio web.

Antes de entregar: documentar procedimiento de resolución completo, versiones,
comandos y verificación de dos flags distintas. No declarar el reto listo solo
porque existen fuentes o metadatos. El historial conserva las notas del borrador v2.
