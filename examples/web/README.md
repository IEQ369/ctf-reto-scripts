# web

Ejemplo educativo de contrato v2. No representa dificultad de torneo.

Preparar con `python tools/validate_challenge.py examples/web --trusted-local`.
Dependencias y entorno: Infraestructura externa administrada por el equipo web; Docker no obligatorio.; instalar el kit antes.
El validador ejecuta la prueba privada que recupera la respuesta desde el artefacto.
