# mobile

Ejemplo educativo de contrato v2. No representa dificultad de torneo.

Preparar con `python tools/validate_challenge.py examples/mobile --trusted-local`.
Dependencias y entorno: JDK 17, Android SDK 35, Gradle 8.9 y Android Gradle Plugin 8.7.3; requieren instalación y comprobación externas.; instalar el kit antes.
El validador ejecuta la prueba privada que recupera la respuesta desde el artefacto.
