# blockchain

Ejemplo educativo de contrato v2. No representa dificultad de torneo.

Preparar con `python tools/validate_challenge.py examples/blockchain --trusted-local`.
Dependencias y entorno: Solidity 0.8.24, Foundry/Anvil y cuentas locales sintéticas; no disponibles en el entorno actual.; instalar el kit antes.
El validador ejecuta la prueba privada que recupera la respuesta desde el artefacto.
